1// euclidean_clustering.h

3// Euclidean Cluster Extraction
4// ----------------------------
5// Region-growing segmentation over a PointCloudSoA using a radius-based
6// neighbor search. Each seed is expanded by a BFS/flood-fill: a point is
7// added to the current cluster if its Euclidean distance to any already-
8// assigned member is ≤ clusterTolerance_.
9//
10// The inner neighbor-query loop is accelerated with RVV (RISC-V Vector
11// Extension) when compiled with RVV_PCL_USE_RVV and __riscv_vector:
12//
13// RVV path – processes VLEN/32 cloud points per vsetvl cycle; computes
14// squared distances with vfsub/vfmul/vfmacc and collects
15// candidate indices via a bit-mask scatter, identical in style
16// to CaravanRadiusSearch.
17//
18// Scalar fallback – plain O(N) sweep per BFS expansion step.
19//
20// Usage:
21// EuclideanClustering ec;
22// ec.setInputCloud(cloud);
23// ec.setClusterTolerance(0.05f);
24// ec.setMinClusterSize(10);
25// ec.setMaxClusterSize(25000);
26// std::vector<std::vector<int>> clusters = ec.extract();
