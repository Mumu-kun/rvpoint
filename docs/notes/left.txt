Updated todo list

Critical items still remaining:

1. **Spatial-index overflow silently drops points**  
   Probe exhaustion uses `continue` instead of returning an error. This can corrupt ROR, SOR, and clustering results.  
   

2. **No atomic result publication**  
   A crash or disk failure can leave partial or stale PCD outputs that downstream systems may interpret as current data.

3. **No processing deadline/watchdog**  
   Large or adversarial clouds can exceed the perception cycle budget without cancellation or timeout handling.

4. **Unchecked integer/index overflow**  
   Cell coordinates, voxel keys, `int` point indices, and size calculations can still overflow or truncate on large/extreme inputs.

5. **Incomplete loader resource limits**  
   Declared PCD point counts and compressed/decompressed sizes can still cause excessive allocation or memory exhaustion.

6. **RANSAC confidence is incomplete**  
   It reports minimum inlier checks, but lacks robust residual-quality validation and a complete confidence/uncertainty contract.

7. **Fabricated normals remain**  
   ROR and skipped-filter paths still assign `(0, 0, 1)` instead of marking normals invalid or computing real normals.

8. **No frame/timestamp/calibration contract**  
   For robotics, the pipeline does not validate coordinate frames, timestamps, sensor calibration, or stale input.

9. **No supervisor-level fail-safe integration**  
   Statuses exist internally, but a consuming autonomy system still needs explicit degraded/failed perception handling.

Trailing whitespace and small performance regressions are non-critical.
