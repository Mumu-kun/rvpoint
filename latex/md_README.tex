This allows for accurate "{}architectural instruction count"{} comparison between Scalar and RVV implementations, independent of emulation speed.\hypertarget{md_README_autotoc_md15}{}\doxysubsection{\texorpdfstring{Running the Benchmark}{Running the Benchmark}}\label{md_README_autotoc_md15}
To generate the instruction count report\+: 
\begin{DoxyCode}{0}
\DoxyCodeLine{scripts/run\_trace\_benchmark.sh}

\end{DoxyCode}
 This will\+:
\begin{DoxyEnumerate}
\item Build the benchmark executable.
\item Run each algorithm in initialization-\/only ({\ttfamily setup}), Scalar ({\ttfamily sc}), and RVV ({\ttfamily rvv}) modes.
\item Use QEMU trace logs to count executed Translation Blocks (TBs).
\item Subtract baseline overhead to report accurate kernel instruction counts.
\item Output results to {\ttfamily results/report\+\_\+sc\+\_\+rvv\+\_\+qemu.\+txt}.
\end{DoxyEnumerate}\hypertarget{md_README_autotoc_md16}{}\doxysubsection{\texorpdfstring{Expected Results}{Expected Results}}\label{md_README_autotoc_md16}

\begin{DoxyEnumerate}
